# Shraddha Singh — PM Portfolio

## Folder Structure

```
portfolio/
├── README.md              ← this file
├── case-studies/          ← one .md file per product/feature story
├── metrics/               ← impact numbers, dashboards, KPIs
├── artifacts/             ← PRDs, roadmaps, wireframes, specs
└── assets/                ← images, logos, screenshots
```

## How to Use

- **case-studies/** — Each file follows: Problem → My Role → Process → Decisions → Outcome → Learnings
- **metrics/** — Quantified impact for each product/initiative; used to strengthen resume bullets and interview stories
- **artifacts/** — Sanitized (no confidential data) versions of real work artifacts
- **assets/** — Supporting visuals referenced in case studies
